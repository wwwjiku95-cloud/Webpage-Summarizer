# 🌐 Webpage Summarizer (Chrome Extension)

An AI-powered Chrome Extension that instantly summarizes any webpage using **Groq Cloud API**. Built for speed, simplicity, and productivity.

---

## 🚀 Features

- ⚡ Lightning-fast AI summaries using Groq Cloud
- 🧠 Smart webpage content extraction
- 📄 One-click summarization of any site
- 🎯 Clean and minimal popup UI
- 🌍 Works on any webpage
- 💡 Lightweight and fast performance

---

## 🛠️ Tech Stack

- HTML, CSS, JavaScript
- Chrome Extension (Manifest V3)
- Groq Cloud API
